# Incognito Router — Privacy Policy

_Last updated: August 2026_

Incognito Router is a browser extension that opens administrator-specified websites in an Incognito/InPrivate window and can optionally close those sessions after a period of inactivity.

## Data Collection

Incognito Router does **not** collect, store, log, sell, or transmit any user data. It does not collect browsing history, personal information, authentication data, location, or website content.

## Local Processing Only

The extension reads a tab's URL/hostname solely to compare it against a configured rule list and determine whether the site should open in an Incognito window.

For sites with an inactivity rule, the extension listens locally for user activity (such as mouse movement or keyboard input) only to reset an inactivity timer and display an on-screen warning before closing the session. This activity is never recorded, stored, or transmitted. All processing happens locally on the user's device.

## Configuration

Routing and inactivity rules are configured either locally by the user (on the extension's options page) or centrally by an organization's IT administrator via managed policy. Configuration data remains on the device.

## Third Parties

Incognito Router does not share any data with third parties and does not use remote code.
